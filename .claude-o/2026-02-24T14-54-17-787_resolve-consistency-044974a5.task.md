## Description
TASK: Improve resolve input quality — structured action summaries with tool inputs

FILE TO MODIFY:
src/loop/state-machine.ts — Improve summarizeRecentActions() and trackEvent() to capture WHAT was done, not just WHICH tool.

Current trackEvent (line ~207-224) stores:
```ts
case "tool_start": this.cur.actions.push(`→ ${event.name}`);
case "tool_result": this.cur.actions.push(`← ${event.name}: ${event.result.slice(0, 500)}`);
```

This loses the tool INPUT — resolve sees "→ shell" / "← shell: 29796209" but not what command was run. Without the input, resolve can't judge whether the action was purposeful.

Change trackEvent to also capture tool_use inputs:
```ts
case "tool_use": {
  const inputStr = typeof event.input?.input === "string"
    ? event.input.input.slice(0, 200)
    : JSON.stringify(event.input).slice(0, 200);
  this.cur.actions.push(`→ ${event.name}(${inputStr})`);
  return null;
}
case "tool_start":
  // tool_start fires before tool_use, skip duplicate
  return { type: "phase_change", phase: "executing" as const };
case "tool_result":
  this.cur.actions.push(`← ${event.name}: ${event.result.slice(0, 300)}`);
  return null;
```

Wait — looking at AgentEvent types, there IS a "tool_use" event type with name and input fields. But currently trackEvent doesn't handle it (it falls through to default). Add a case for it.

Actually, looking more carefully at the event types:
```ts
| { type: "tool_use"; name: string; input: Record<string, unknown> }
| { type: "tool_start"; name: string }
```

tool_start fires when execution begins, tool_use has the input. Currently tool_start captures `→ name` and tool_use falls through to default (ignored). Change:

```ts
case "tool_use": {
  const raw = event.input?.input;
  const inputStr = typeof raw === "string" ? raw.slice(0, 200) : "";
  if (inputStr) {
    // Replace the last action entry (which was "→ name" from tool_start) with input details
    const lastIdx = this.cur.actions.length - 1;
    if (lastIdx >= 0 && this.cur.actions[lastIdx]!.startsWith("→")) {
      this.cur.actions[lastIdx] = `→ ${event.name}(${inputStr})`;
    }
  }
  return null;
}
```

This way resolve sees: `→ shell(awk '{s+=$1} END {print s}' /workspace/data/numbers.txt)` instead of just `→ shell`.

Also improve summarizeRecentActions() for clarity:
```ts
private summarizeRecentActions(): string {
  if (this.cur.actions.length === 0) return "(no actions taken)";
  const actions = this.cur.actions.slice(-30);
  return actions.join("\n");
}
```
Increase from -20 to -30 to capture more context for resolve.
