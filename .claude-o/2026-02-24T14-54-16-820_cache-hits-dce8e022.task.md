
# Task: cache-hits

## Description
TASK: Fix cache hits — add dedicated memory cache breakpoint

CONTEXT: The LLM layer (src/llm/index.ts) already has cache_control on system prompt, last user message, and last tool. BUT cache reads are always 0 across all agents. The likely reason: agents only get 1 agentic loop iteration per cycle (maxCycleCost too low), so there's no second call to benefit from the cache. Another task is fixing maxCycleCost. This task ensures caching WORKS when agents do get multiple iterations.

FILE TO MODIFY:
src/loop/state-machine.ts — In the cycle() method (~line 183-203), add a cache breakpoint on the LAST memory message so the system+memories prefix is explicitly cached for all subsequent iterations within the agentic loop.

Current code:
```ts
const memoryMessages = this.state.memories.formatAsMessages(MEMORY_TOKEN_BUDGET);

for await (const event of this.loop.run({
  systemPrompt: this.state.config.systemPrompt,
  messages: [...memoryMessages, this.buildAwarenessMessage(toolNames)],
  ...
```

Change: Before spreading memoryMessages, mark the last memory message with cache_control so the memory prefix is explicitly cached:
```ts
const memoryMessages = this.state.memories.formatAsMessages(MEMORY_TOKEN_BUDGET);

// Mark last memory message for caching so system+memories prefix is a cache hit
// on subsequent agentic loop iterations (tool use rounds)
if (memoryMessages.length > 0) {
  const lastMem = memoryMessages[memoryMessages.length - 1]!;
  if (typeof lastMem.content === "string") {
    memoryMessages[memoryMessages.length - 1] = {
      ...lastMem,
      content: [{ type: "text" as const, text: lastMem.content, cache_control: { type: "ephemeral" as const } }],
    };
  }
}
```

ALSO: src/state/memory.ts formatAsMessages() returns MessagePair[] (role + content string). The type needs to be compatible with Anthropic.MessageParam for the cache_control to work. Check that the spread into this.loop.run messages works with the modified content format. The Anthropic API accepts content as string OR array of blocks, so this should work.

After changes, run: npx tsc --noEmit
Commit with a clear message.
